# Project-Scoped Rules — PulseLab (Pulse-main)

## Session & Documentation Organization
- Store all session reviews, task notes, plans, walkthroughs, and research documentation within the project's local directory (`Pulse-main/docs/`, `Pulse-main/output/`, or `.agents/`), instead of referencing or saving to external repositories like `tiny_steward`.
- Each project must maintain its own autonomous local documentation footprint.
